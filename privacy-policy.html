Privacy Policy — Browser Lock

Last updated: September 2026

Browser Lock ("the extension") is a Chrome extension that locks the browser with a password on every restart. This privacy policy explains what data the extension handles and how.

Data Collection

Browser Lock does not collect, transmit, sell, or share any user data with the developer, Anthropic, or any third party. The extension does not use analytics, tracking, or remote servers of any kind.

Data Stored Locally

The extension stores the following data locally on your device, using Chrome's built-in storage.local API:

  • A salted SHA-256 hash of the password you set (the plain-text password itself is never stored)
  • The current lock state of the browser (locked or unlocked)
  • The URLs of tabs that were open when the browser was locked, so they can be restored after unlocking

This data never leaves your device. It is not synced, uploaded, or accessible to anyone other than you, on your own browser.

Permissions

The extension requests the following permissions, used solely to provide its core locking functionality:

  • storage — to save the password hash, lock state, and saved tab URLs locally
  • tabs — to detect new tabs and redirect them to the lock screen, and to restore previously open tabs after unlocking
  • webNavigation — to detect navigation attempts in existing tabs and redirect them to the lock screen while locked

Third-Party Sharing

No data collected or stored by this extension is shared with any third party, advertiser, or external service.

Children's Privacy

The extension does not knowingly collect any information from anyone, including children, as it does not collect data at all.

Changes to This Policy

If this policy changes in the future, an updated version will be posted at this same URL.

Contact

If you have questions about this privacy policy, please contact the developer through the Chrome Web Store listing.
